# RTCNext
## Aplikasi Telepon Indonesia
RTCNext Adalah Sebuah Aplikasi Telepon Indonesia. RTCNext Rilis Pada 24 Oktober 2026. Fitur-fitur Unik RTCNext Adalah:
* Bertelepon Ganda - Telepon Dengan 4 Orang Atau Dibawah 4 orang.
* Grup - Mirip Dengan WhatsApp Bedanya Undangan Harus disetujui oleh pengguna yang diundang.
* Akun Tidak Memakai Nomor Tapi Nama Akun.
